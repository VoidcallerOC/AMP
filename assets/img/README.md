# Image assets

This starter ships with **no stock photography** — the hero and featured
sections use hand-built CSS illustrations so the site stays fast and isn't
tied to any particular business or industry. When a client has real photos,
drop them in here and swap the corresponding CSS/HTML.

- `brand/` — logo, favicon, wordmark files
- `hero/` — hero section photography (if replacing the CSS illustration)
- `products/` — product, service, or offering photos
- `events/` — event/community photos
- `content/` — featured content, blog, or announcement images
- `social/` — Open Graph / social share image (`og-image.jpg`, 1200×630)

Keep filenames lowercase and hyphenated (`storefront-exterior.jpg`), and
compress before committing — this is a zero-build static site, so whatever
you add here is served exactly as-is with no image optimization pipeline.
