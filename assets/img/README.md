# AMP image assets

These images are used by the AMP Adaptive Movement Parkour demo and were selected from official Adaptive Movement Parkour image results.

- `hero/` — hero facility and logo imagery
- `programs/` — program and facility imagery used by the program cards
- `brand/` — supporting schedule graphic and favicon

Keep image references local and use descriptive alt text. The site remains zero-build and serves these assets directly.
