# New client checklist

Copy this into the client Drive folder when you start a job.

## Intake
- [ ] Intake brief filled
- [ ] Logo received
- [ ] Photos received
- [ ] Hours, address, phone confirmed
- [ ] Domain owned or to purchase
- [ ] Deposit received

## Build
- [ ] New private repo from this template
- [ ] Replace `Client Name` + headline + lede in `index.html`
- [ ] Update `BUSINESS` and `HOURS` in `assets/js/main.js`
- [ ] Set `--accent` / `--bg` in `assets/css/styles.css`
- [ ] Swap favicon / logo
- [ ] Drop photos into `assets/img/` and replace gallery placeholders
- [ ] Update OG tags + canonical URL
- [ ] Preview on Vercel

## Launch
- [ ] One revision pass
- [ ] Domain pointed at Vercel
- [ ] Delivery email sent
- [ ] Balance invoiced / paid
- [ ] Tracker set to Live
- [ ] Drive folder moved to `03_Delivered`
